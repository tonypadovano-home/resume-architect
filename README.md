# resume-architect

A professional resume builder application built with React, TypeScript, and Vite.

## Features

- Clean, professional resume layout
- Modular resume sections: Summary, Experience, Education, Skills
- Print-friendly design
- TypeScript-powered data models

## Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the resume in your browser.

### Build

```bash
npm run build
```

### Test

```bash
npm run test
```

### Lint

```bash
npm run lint
```

## Customization

To customize the resume content, edit the data file at `src/data/resumeData.ts`.

## Print

The resume is print-optimized. Use your browser's print function (Ctrl+P / Cmd+P) to print or save as PDF.
